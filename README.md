# Dough & Drizzle 🍩

A donut and coffee shop website built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

**[Live Demo](https://sitradaru.github.io/restaurant-page/)** · **[GitHub Repository](https://github.com/sitradaru/restaurant-page)**

Dough & Drizzle features a welcoming homepage, a menu showcasing donuts and drinks, and a contact page with the shop's information and location.

## Features

- **Home page** — Introduces the shop and provides quick links to the menu and contact page.
- **Menu page** — Displays donuts and drinks with product images and prices.
- **Contact page** — Presents the shop's contact information, opening hours, location, and illustration.
- **Dynamic page rendering** — Builds page content using JavaScript and the DOM.
- **Interactive navigation** — Switches between pages without reloading the entire page.
- **Responsive asset bundling** — Uses Webpack to bundle JavaScript, stylesheets, images, and fonts.

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone git@github.com:sitradaru/restaurant-page.git
   ```

2. Navigate into the project directory:

   ```bash
   cd restaurant-page
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

### Running the Project

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.

### Production Build

To generate an optimized production build, run:

```bash
npm run build
```

Webpack outputs the generated files to the `dist` directory.
